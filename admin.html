Mock questions and answers

Open a level and semester. Each mock has a space for the questions (HTML) and a space beside it for the answers, for every subject.
How shuffling and the answers work 
The shuffling is only what the student SEES. Inside the HTML each question keeps its original number and each option keeps its original letter, whatever order it is shown in. When the student finishes, the page sends back the ORIGINAL letter they picked for each ORIGINAL question number, with "-" for a question they skipped.

So your answer key is always written in the original order, A to D as you wrote the questions, no matter how each student's paper was shuffled. Admin matches question 1 to the first letter in your key, question 2 to the second, and so on.

The page must send:
window.parent.postMessage({
  type: "indigene-mock-done",
  answers: ["B","A","-","D"]
}, "*");

Answers box: type the letters like C,A,B,D (or CABD). No correct answers go inside the HTML.
Keep each HTML file under 900 KB. Do not use localStorage or Firebase inside it.
